# 专利创新点提取与撰写技能

从电力系统领域的软件工程项目中提取技术创新点，对技术方案进行升华拔高，并按照专利技术交底书格式撰写专利初稿。

## 工作流程

1. **项目工程全面探索** — 深入分析项目目录结构、核心代码、文档和数据文件
2. **提取创新点** — 从算法、模型、数据处理、系统架构、应用等维度识别技术创新
3. **技术方案升华** — 将工程级创新升华为专利级技术方案（向上抽象、问题导向、建立因果链）
4. **检索真实专利与文献** — 通过网络检索真实专利和论文，严禁凭空捏造现有技术
5. **撰写专利初稿** — 按标准技术交底书格式输出专利正文和附图绘制说明

## 输出

- `专利初稿_[专利名称].md` — 专利正文（含公式、图表占位）
- `专利附图说明_[专利名称].md` — 附图绘制说明（元素清单、色号、连接关系）

## 写作规范要点

- **已有技术/产品的不足**：一整段流式叙述，按技术路线分类递进，不分小节、不编号列举。专利引用以括号内标注方式自然融入段落（如"如专利 CN119813310A，2025"），篇幅控制在300-500字
- **措辞规范**：使用"有待提升""存在不足""尚未""未充分考虑"等客观表述，严禁全盘否定现有技术
- **引用真实性**：所有引用的专利和文献必须来自真实检索结果，严禁捏造

## 触发条件

当用户提到"提取创新点"、"撰写专利"、"专利初稿"、"技术交底书"、"申请专利"、"专利挖掘"等关键词时触发，特别是在电力系统、微电网、光伏、储能、负荷预测、故障诊断等领域。
