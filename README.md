# 专利创新点提取与撰写技能

从电力系统领域的软件工程项目中提取技术创新点，对技术方案进行升华拔高，并按照专利技术交底书格式撰写专利初稿。

## 功能

- 深入分析项目工程代码，识别技术创新点
- 将工程级创新升华为专利级技术方案
- 按标准技术交底书格式撰写完整专利初稿
- 为每张图提供详细的绘制说明（元素清单、色号、连接关系）

## 输出

- `专利初稿_[专利名称].md` — 专利正文
- `专利附图说明_[专利名称].md` — 附图绘制说明

## 触发条件

当用户提到"提取创新点"、"撰写专利"、"专利初稿"、"技术交底书"、"申请专利"、"专利挖掘"等关键词时触发，特别是在电力系统、微电网、光伏、储能、负荷预测、故障诊断等领域。
